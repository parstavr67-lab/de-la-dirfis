# Εκτροφείο de la Dirfis — διαδικτυακή έκδοση (πρώτη έκδοση)

Αυτή είναι μια πρώτη διαδικτυακή βάση για πρόσβαση από υπολογιστή και Android tablet. Περιλαμβάνει σύνδεση χρήστη και καταχώριση/αναζήτηση/επεξεργασία/διαγραφή στις 7 ενότητες που υπάρχουν στο αρχικό `pelates.py`: Σκύλοι, Ζευγαρώματα, Γέννες, Κουτάβια, Ενδιαφερόμενοι/Πελάτες, Εκπαίδευση, Οικονομικά.

**Δεν είναι πλήρης αντιγραφή όλων των λειτουργιών της εφαρμογής Tkinter.** Οι ειδικές αναφορές/εκτυπώσεις και η οθόνη backup του αρχικού προγράμματος δεν έχουν μεταφερθεί σε αυτή την πρώτη έκδοση. Να γίνει δοκιμή πριν περαστούν πραγματικά δεδομένα.

## Σημαντικό για δωρεάν φιλοξενία

Το Render Free μπορεί να κοιμίζει την εφαρμογή μετά από αδράνεια και δεν διατηρεί αρχεία που γράφονται στον τοπικό δίσκο. Γι' αυτό η εφαρμογή χρησιμοποιεί εξωτερική PostgreSQL βάση, όχι SQLite πάνω στον server. Η δωρεάν βάση Supabase μπορεί να παγώσει μετά από περίοδο χαμηλής δραστηριότητας. Για πραγματικά σημαντικά δεδομένα, κράτα τακτικά ξεχωριστό backup.

## Αρχεία

- `app.py`: εφαρμογή web.
- `requirements.txt`: εξαρτήσεις.
- `render.yaml`: βασικές ρυθμίσεις φιλοξενίας Render.
- `migrate_sqlite_to_postgres.py`: εργαλείο εφάπαξ αντιγραφής δεδομένων από SQLite σε PostgreSQL. **Δεν διαγράφει ούτε τροποποιεί την αρχική βάση.** Η εντολή εισαγωγής αδειάζει τους αντίστοιχους πίνακες της απομακρυσμένης βάσης, άρα τρέχει μόνο μία φορά σε ολοκαίνουργια βάση ή αφού επιβεβαιωθεί ότι επιτρέπεται η αντικατάστασή τους.

## Γενική διαδικασία εγκατάστασης

1. Κράτησε αντίγραφο του `de_la_dirfis.db` και του αρχικού `pelates.py` σε ασφαλές σημείο.
2. Δημιούργησε λογαριασμό Supabase και ένα νέο PostgreSQL project. Αντέγραψε το connection string από το Dashboard → Connect. Χρησιμοποίησε σύνδεση με SSL.
3. Ανέβασε αυτόν τον φάκελο σε ιδιωτικό repository στο GitHub (μην ανεβάσεις τη βάση, το connection string ή κωδικούς).
4. Στο Render δημιούργησε Web Service από το repository και επίλεξε Free. Build command: `pip install -r requirements.txt`. Start command: `gunicorn app:app --workers 1 --threads 4 --timeout 120`.
5. Στα Environment Variables του Render όρισε:
   - `DATABASE_URL`: το connection string PostgreSQL του Supabase
   - `SECRET_KEY`: τυχαίο μυστικό τουλάχιστον 32 χαρακτήρων
   - `APP_USERNAME`: το όνομα σύνδεσης που θα χρησιμοποιείς
   - `APP_PASSWORD`: ισχυρό, μοναδικό κωδικό
6. Άνοιξε το URL που δίνει το Render και έλεγξε ότι η σελίδα σύνδεσης και το `/health` λειτουργούν.
7. Για μεταφορά παλιών εγγραφών, κατέβασε το repository στον υπολογιστή και βάλε προσωρινά το `DATABASE_URL` στο περιβάλλον του υπολογιστή. Έπειτα εκτέλεσε:
   `python migrate_sqlite_to_postgres.py "C:\Users\...\de_la_dirfis.db"`
8. Έλεγξε τον αριθμό εγγραφών σε κάθε ενότητα από το web app. Μην αλλάξεις/διαγράψεις το παλιό πρόγραμμα ή τη βάση του μέχρι να επιβεβαιωθεί ότι όλα μεταφέρθηκαν σωστά.

## Ασφάλεια

- Μη στείλεις κωδικούς ή το `DATABASE_URL` σε μήνυμα ή σε δημόσιο repository.
- Χρησιμοποίησε ισχυρό κωδικό, και κράτησε το repository ιδιωτικό.
- Η εφαρμογή χρησιμοποιεί HTTPS όταν φιλοξενείται στο Render, cookies συνεδρίας και token προστασίας φόρμας.
- Το απλό login εδώ προορίζεται για έναν διαχειριστή. Δεν είναι ακόμη πολυχρηστικό σύστημα με ρόλους χρηστών.
- Πριν από πραγματική χρήση, κάνε δοκιμές με δοκιμαστικές εγγραφές και επιβεβαίωσε ότι τα αντίγραφα ασφαλείας λειτουργούν.
